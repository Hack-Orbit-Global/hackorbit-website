How to contribute to Hack Orbit

Contribution is at the heart of Hack Orbit. Here's how to go from visitor to contributor.

Four steps to your first contribution

Find a project

Browse the Projects page for official Hack Orbit repositories. Official repos are where your contributions are tracked automatically.

Pick a good first issue

Look for issues labelled good first issue or help wanted in the official repositories. Introduce yourself, ask questions, and claim an issue before starting.

Open a pull request

Fork the repository, make your change, and open a pull request. Follow each repo's contributing guide and keep PRs focused and well-tested.

Get recognised

When your pull request merges, your work is recognised — and you're officially a Hack Orbit contributor.

Contribution guidelines

Do

  • · Discuss significant changes before implementing them
  • · Write tests alongside your changes
  • · Keep pull requests small and focused
  • · Be respectful and constructive in reviews
  • · Ask for help when you're stuck — that's what a community is for

Avoid

  • · Opening PRs without reading the contributing guide
  • · Scope-creeping a PR beyond its stated purpose
  • · Claiming issues you haven't started
  • · Submitting the same contribution to multiple organisations
Where contributions count

Everything happens in official repos

Hack Orbit's work happens in its official GitHub organisation's repositories. Merged pull requests, resolved issues, and submitted code reviews are what move the organisation forward.

Hack Orbit's work is public by design — everything lives in the official GitHub organisation, so anyone can see what's happening and jump in.
